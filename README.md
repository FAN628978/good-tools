### yt-dlp + FFmpeg

高效的视频下载与处理工具组合。

* `yt-dlp`：支持 Bilibili、YouTube 等平台的视频下载
* `FFmpeg`：用于音视频合并、转码与处理
* 支持高码率、字幕、批量下载、自动合并等功能

支持通过 `uv` 快速安装相关 Python 工具链：

```bash
uv tool install yt-dlp
```

FFmpeg 可通过：

```bash
winget install Gyan.FFmpeg
```

安装后即可实现：

```bash
yt-dlp <url>
```

自动下载并合并音视频流。
